┌──────────────────────────────────────────────────────────────────────┐
│ PERINTAH DASAR                                                       │
└──────────────────────────────────────────────────────────────────────┘

  python main.py                    → Semua akun, 2 workers, headless
  python main.py 10                 → 10 akun, 2 workers
  python main.py 10 4               → 10 akun, 4 workers
  python main.py 10 4 --visible     → 10 akun, 4 workers, browser tampil

┌──────────────────────────────────────────────────────────────────────┐
│ MODE REGISTER (Buat Akun Baru)                                       │
└──────────────────────────────────────────────────────────────────────┘

  python main.py 10 4 --register
  python main.py 10 4 --register --visible

  File input: registerakun.txt

┌──────────────────────────────────────────────────────────────────────┐
│ MODE MANUAL (⭐ RECOMMENDED)                                         │
└──────────────────────────────────────────────────────────────────────┘

  python main.py --manual --visible
  python main.py 1 1 --manual --visible

  Workflow:
    1. Bot buka browser
    2. Anda login manual ke Kiro via Google
    3. Bot capture token otomatis
    4. Success rate: 100%!

┌──────────────────────────────────────────────────────────────────────┐
│ UTILITY COMMANDS                                                     │
└──────────────────────────────────────────────────────────────────────┘

  python main.py --list             → Lihat akun yang sudah diproses
  python main.py 10 4 -a custom.txt → Custom file input
  python main.py 10 4 -d 10         → Delay 10 detik antar batch

    newemail1@gmail.com:password123
    newemail2@gmail.com:password456

  account.json:
    Log semua akun dengan status success/fail

┌──────────────────────────────────────────────────────────────────────┐
│ MANUAL INJECT KE 9ROUTER                                             │
└──────────────────────────────────────────────────────────────────────┘

  1. Generate tokens:
     python main.py 10 4

  2. Buka dashboard 9router:
     http://localhost:20128/dashboard

  3. Pilih provider (anthropic/openai/dll)

  4. Copy refresh token dari kiro_tokens.txt
     Format: part1:part2 (kedua bagian diperlukan)

  5. Paste ke form 9router dan save

┌──────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                      │
└──────────────────────────────────────────────────────────────────────┘

  Google Detection:
    → Gunakan mode manual: python main.py --manual --visible
    → Kurangi workers: python main.py 5 1
    → Tambah delay: python main.py 10 2 -d 10

  Halaman Blank:
    → Gunakan --visible untuk debug
    → Gunakan mode manual
    → Install Chrome di system

  Captcha:
    → Mode manual dan solve manual
    → Script pause 180 detik otomatis

  Token Tidak Ditemukan:
    → Gunakan --visible untuk debug
    → Pastikan redirect ke app.kiro.dev berhasil
    → Gunakan mode manual

┌──────────────────────────────────────────────────────────────────────┐
│ TIPS & BEST PRACTICES                                                │
└──────────────────────────────────────────────────────────────────────┘

  ✓ Start small: Test 1-2 akun dulu
  ✓ Use manual mode: Untuk akun penting
  ✓ Monitor rate limits: Tambah delay jika perlu
  ✓ Batch kecil: Max 5-10 akun per run
  ✓ Resume support: Script auto-skip akun sukses
  ✓ Visible mode: Untuk debugging

┌──────────────────────────────────────────────────────────────────────┐
│ COMMAND-LINE ARGUMENTS                                               │
└──────────────────────────────────────────────────────────────────────┘

  Positional:
    jumlah              Jumlah akun (default: all)
    workers             Jumlah worker (default: 2)

  Options:
    -a, --accounts      File akun (default: account.txt)
    -o, --output        File output (default: kiro_tokens.txt)
    -d, --delay         Delay antar batch detik (default: 3)
    --visible           Tampilkan browser
    --register          Mode register akun baru
    --manual            Mode semi-auto (login manual)
    --list              List akun dari account.json
    --chrome            Gunakan system Chrome

┌──────────────────────────────────────────────────────────────────────┐
│ WORKFLOW                                                             │
└──────────────────────────────────────────────────────────────────────┘

  1. Navigasi ke kiro.dev
  2. Klik "Sign in"
  3. Klik "Continue with Google"
  4. Login Google (email + password)
  5. Handle consent page ("Allow")
  6. Redirect ke app.kiro.dev
  7. Capture refresh token via network interception
  8. Save ke kiro_tokens.txt & account.json

┌──────────────────────────────────────────────────────────────────────┐
│ TOKEN CAPTURE STRATEGY                                               │
└──────────────────────────────────────────────────────────────────────┘

  Primary:   Network Interception (/oauth2/token)
  Fallback1: localStorage polling (setiap 2s)
  Fallback2: URL hash parsing
  Fallback3: Cookies scanning

┌──────────────────────────────────────────────────────────────────────┐
│ FAQ                                                                  │
└──────────────────────────────────────────────────────────────────────┘

  Q: Kenapa tidak bisa auto-inject ke 9router?
  A: 9router tidak support provider "kiro". Inject manual via dashboard.

  Q: Format refresh token Kiro?
  A: Format: part1:part2 (2 bagian dipisahkan colon)

  Q: Token akan expired?
  A: Ya, monitor status di aplikasi yang menggunakan token.

  Q: Success rate mode auto vs manual?
  A: Auto: 60-80%. Manual: 100% (jika login berhasil).
