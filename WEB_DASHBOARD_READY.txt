   kiro start

   python kiro.py start

📋 WORKFLOW:

1. Start server: kiro start
2. Open browser: http://localhost:8000
3. Add accounts:
   - Single: masukkan email & password satu per satu
   - Bulk: paste multiple accounts (format: email:password)
4. Configure settings (workers, delay, visible mode)
5. Click "Start Processing"
6. Monitor progress real-time
7. Export tokens (click "Export Tokens" button)
8. Manual inject ke 9router via dashboard 9router
